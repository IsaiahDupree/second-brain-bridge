What SecondBrainBridge does

SecondBrainBridge lets an AI assistant (e.g. ChatGPT) search and read the Obsidian-style Markdown notes in a vault folder on your own Mac, and — on the Pro plan — create new notes and view your backlink graph. Note operations run locally on your Mac via an agent you install; the hosted relay only forwards each request while it is in flight and does not store your note content.
